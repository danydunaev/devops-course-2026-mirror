# Мои цели на семестр

## Цель 1. Освоить Docker и контейнеризацию
Научиться писать Dockerfile для Python-приложений, собирать образы и запускать контейнеры.
К концу семестра — уметь упаковать свой пет-проект (телеграм-бот или скрипт) в Docker-образ
и запускать его одной командой `docker run`.

## Цель 2. Настроить CI/CD пайплайн на GitHub Actions
Разобраться, как автоматически запускать тесты и линтеры при каждом push в репозиторий.
К концу семестра — иметь рабочий workflow, который прогоняет тесты и собирает Docker-образ
при каждом коммите в main.

## Цель 3. Освоить основы Infrastructure as Code (Terraform / Ansible)
Понять, как описывать инфраструктуру кодом, а не настраивать её вручную через веб-интерфейс.
К концу семестра — уметь поднять простой сервер в Yandex Cloud через Terraform
и настроить его через Ansible playbook.
