**1. Ветвление:**
- **Git:** ветка — просто указатель на коммит. Создаётся мгновенно, локально, без сети.
- **SVN:** ветка — копия директории в репозитории. Требует обращения к серверу, а слияния — тяжёлые серверные операции.

**2. Коммит в SVN без интернета:**
- **Нет.** SVN централизован — `commit` идёт напрямую на сервер. Без сети нельзя.
- В Git `commit` локальный, сеть нужна только для `push`.

**3. Где SVN ещё лучше:**
- Огромные бинарные файлы (можно не тянуть всю историю).
- Строгий контроль доступа по папкам и блокировки файлов.
- Аудит и регулируемые отрасли (последовательные ревизии).
- Простые линейные проекты без сложного ветвления.
